# ☕ Java Console Applications

A collection of beginner-friendly Java console applications created to practice core Java programming concepts, problem-solving, and basic application logic.

## 📌 About

This repository contains simple Java console-based applications developed while learning and practicing Java programming.

The projects focus on understanding basic programming concepts such as:

* Variables and data types
* Conditional statements
* Loops
* User input
* Methods
* Basic program logic
* Console-based interaction

## 📂 Projects

### 🏦 ATM Application

A simple console-based ATM application that demonstrates basic banking operations and user interaction.

**Concepts practiced:**

* User input
* Conditional statements
* Menu-driven programming
* Basic transaction logic

### 🎯 Number Guessing Game

A console-based game where the user attempts to guess a randomly generated number.

**Concepts practiced:**

* Random number generation
* Loops
* Conditional statements
* User input
* Game logic

## ▶️ How to Run

### 1. Install Java

Make sure Java JDK is installed on your computer.

Check the installation:

```bash
java --version
```

### 2. Compile the program

For the ATM application:

```bash
javac Atm.java
```

### 3. Run the program

```bash
java Atm
```

For the Number Guessing Game:

```bash
javac NumberGuessing.java
java NumberGuessing
```
